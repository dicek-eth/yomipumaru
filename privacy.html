プライバシーポリシー

対象：Yomipumaru Publisher（YouTube チャンネル「よみぷまる」の運営者が使う社内ツール）／制定：2026年10月14日

1. 利用者

本ツールを使うのは、チャンネルの運営者本人だけです。一般の方に提供するものではなく、運営者以外の Google アカウントでのログインは想定していません。

2. 使う情報（YouTube API サービス）

本ツールは YouTube API サービスを使い、運営者が OAuth で許可した運営者自身の YouTube チャンネルについて、次のことだけを行います。

  • 運営者が作った動画を、運営者のチャンネルにアップロード・予約公開し、サムネイルを設定する
  • 運営者自身の動画の公開情報（再生数・高評価数・コメント数など）を読む

ほかの YouTube ユーザーの個人情報は、集めることも、保存することもありません。

3. 保存と共有

  • 認証に使うトークンは、運営者の Mac の中にだけ保存します。
  • 読み取った統計は、運営者だけが見る管理用のページと、運営者の Mac の中のファイルにだけ保存します。
  • 情報を第三者に販売・提供することはありません。

4. 保存期間と削除

  • YouTube API サービスから取得した情報（動画の統計など）は、運営者の Mac の中で日ごとに更新し、統計の数値は最長36か月、それ以外の情報（動画のタイトルなど）は30日以内に更新または削除します。
  • 許可が取り消された場合、または運営者が利用をやめた場合、保存しているトークンと YouTube API サービスから取得した情報は30日以内に削除します。
  • 削除の依頼・お問い合わせは、下記の連絡先で受け付けます。

5. 許可の取り消し

運営者は、Google アカウントのセキュリティ設定（サードパーティのアクセス）から、いつでも本ツールへの許可を取り消せます。取り消すと、保存されたトークンは使えなくなります。

6. 関連する規約

本ツールは YouTube API サービスを使っています。利用にあたっては YouTube 利用規約 と Google プライバシーポリシー が適用されます。

Privacy Policy (English)

Who uses it. Yomipumaru Publisher is a private, internal tool used only by the owner of the YouTube channel "Yomipumaru". It is not offered to the public, and no other Google accounts are expected to sign in.

What it does with YouTube API Services. Using YouTube API Services, and only for the owner's own channel that the owner authorized via OAuth, it (a) uploads and schedules the owner's videos and sets their thumbnails, and (b) reads public statistics (views, likes, comments) of the owner's own videos. It does not collect or store personal data of any other YouTube users.

Storage and sharing. OAuth tokens are stored only on the owner's Mac. Statistics are stored only on the owner's Mac and in a private dashboard viewed only by the owner. No data is sold or shared with third parties.

Retention and deletion. Data obtained from YouTube API Services is refreshed daily on the owner's Mac. Statistics are kept for up to 36 months; other data (such as video titles) is refreshed or deleted within 30 days. If authorization is revoked or the tool is no longer used, the stored tokens and all data obtained from YouTube API Services are deleted within 30 days. Deletion requests can be sent to the contact address below.

Revoking access. Access can be revoked at any time at Google Account security settings.

Related terms. By using this tool, the YouTube Terms of Service and the Google Privacy Policy apply.

Contact. support.yomupu@gmail.com
